# GyrB AI-CADD Platform

An AI-assisted computational drug discovery platform for DNA gyrase B (GyrB).

## Modules

- Ligand-Based Drug Design (LBDD)
- Structure-informed SBDD scoring
- Constrained de-novo analogue generation
- ADMET / drug-likeness profiling
- Applicability-domain assessment
- Integrated CADD prioritization

## Structural reference

PDB: 4DUH

## Important scientific limitation

The SBDD component is a structure-informed similarity/proxy score.
It is NOT molecular docking and does not calculate binding free energy.

The generated compounds are computational candidates and require
experimental validation before biological conclusions can be made.
